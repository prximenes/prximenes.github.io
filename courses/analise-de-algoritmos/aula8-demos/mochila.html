🎒 A caverna do tesouro

Você é um explorador numa caverna cheia de tesouros, mas sua mochila aguenta no máximo C kg. A pergunta de decisão (Slide 7) é: dá para levar pelo menos V moedas de valor sem estourar a mochila? Escolher os itens é difícil. Conferir uma escolha pronta (Slide 8) é só somar.

Cada quadradinho é um subconjunto de itens (cada item entra ou não: 2 opções por item, 2⁴ = 16 mochilas). O resolvedor sem atalhos precisa testar um por um. A sua mochila atual é o quadradinho com o anel dourado: verificar é olhar só ele.

📏 E com mais itens?

Computador fazendo 10⁹ operações por segundo. Arraste n (os números do Slide 7 são n = 20, 60 e 100).

n = 20
Mochilas possíveis — 2ⁿ
Resolver (força bruta) — 2ⁿ · n operações
Verificar — 2n operações
💡 O que levar para a aula
O atalho guloso falha. Na instância do slide, pegar o mais valioso primeiro (🗿 + 🏺) dá 11 moedas, mas 👑 + 💍 + 🏺 dá 12. Não existe regra simples conhecida que sempre acerte.
Resolver = procurar no tabuleiro inteiro. Cada item a mais dobra o número de quadradinhos: 2ⁿ.
Verificar = olhar um quadradinho. Some os pesos, some os valores, compare com C e V: O(n).
O oráculo (botão 🔮) é a pessoa que “sopra” a resposta. Se a resposta é SIM, existe um sopro que o verificador aceita. É exatamente isso que significa estar em NP.
